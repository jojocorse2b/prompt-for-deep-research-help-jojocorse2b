# Prompt format

## Required sections

### Objective
State the decision, audience, time horizon, and why the research matters.

### Context
Include only verified project facts. Attach `[unknown]` to missing facts.

### Investigate
Use numbered questions grouped by one research mission. Include compatibility,
cost, risks, alternatives, implementation effort, and a counter-case where
relevant.

### Source Requirements
Prioritize primary sources, require URLs and dates, and ask for source quality
and conflicts to be reported.

### Output Format
Specify the exact report shape: executive summary, comparison matrix,
recommendation, assumptions, evidence, contradictions, limitations, and next
steps as appropriate.

### Constraints
List scope boundaries, budget, timeline, platform, rejected options, and
questions that must not be answered by guesswork.
